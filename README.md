## 🌟 Key Features

### 1. 👑 Shahi Khansama AI Concierge (Powered by Groq Cloud & Qwen)
- Intelligent AI dining assistant powered by `qwen/qwen3.8-27b` via Groq's high-speed inference (~500 tokens/s).
- **Strict Restaurant-Only Guardrails**: Dedicated solely to The Royal Rasoi, menu inquiries, food recommendations, and reservations.
- **Smart Menu Search**: Instant AI suggestions directly from the menu search bar and empty states.
- Floating mobile-docked drawer with quick suggestion chips, live chat, and instant quick-links.

### 2. 📱 100% Mobile-First Luxury Design
- Mobile-optimized layout designed specifically for on-premise diners and smartphone users.
- Persistent mobile bottom navigation bar with live cart item counter, running bill total, and fast actions.
- Glassmorphic royal burgundy & gold theme with smooth animations powered by `motion/react`.

### 3. 🍽️ Interactive Dastarkhwan Menu Book (220+ Delicacies)
- 6 royal categories: *Starters*, *Curries*, *Biryani & Rice*, *Chinese & Snacks*, *Breads*, and *Beverages*.
- Zero-lag pagination (9 dishes per page).
- Veg / Non-Veg diet toggles and subcategory filter pills.
- Official scanned 7-page menu book viewer modal.

### 4. 🛒 Easy 1-Click WhatsApp Ordering
- In-place `[+ Add]` and `[-] [ 1 ] [+]` quantity controls directly on dish cards.
- Supports 3 fulfillment modes:
  - 🍽️ **Dine-In**: Specify Table number.
  - 🥡 **Takeaway / Pickup**: Fast pickup from Sadikpur.
  - 🛵 **Home Delivery**: Delivery across Patna City.
- 1-click WhatsApp order generator pre-filling complete itemized receipt and special cooking instructions.

### 5. 🌟 360° Spinning Showcase
- Continuous 360° spin and breathing zoom animations for signature white round plate dishes.

### 6. 📅 Imperial Table & Banquet Reservations
- Dedicated online booking for intimate dining and 150-guest private banquet hall.
- Automatic booking reference ID generator with instant WhatsApp confirmation.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm / yarn / pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/dk2017044/Royal-resturant.git

# Navigate to project directory
cd Royal-resturant

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
npm run build
npm run preview
```
